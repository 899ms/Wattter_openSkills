# 9号漫画 比喻实战目录

本文件记录经过实战验证的比喻方案——哪些成功、哪些失败、哪些渲染出了问题。供生成时参考，避免重蹈覆辙。

---

## ✅ 成功比喻（有效且好笑）

| 主题 | 比喻 | 为什么成功 |
|:---|:---|:---|
| 系统架构 | 合租房马桶堵了谁来通 | 低级日常 + 每个人都有体验 + "谁负责"的混乱感完美映射微服务职责边界 |
| 投资组合 | 自助餐怎么拿最划算 | 人人都经历过"眼大肚子小" + 选择策略和资源分配本质相同 |
| 数据库索引 | 菜市场摊主用本子记"土豆在第三排" | 不识字的老太太也能秒懂 + 索引就是"本子"的直觉映射 |
| A/B 测试 | 两个相亲对象同时聊，看谁先回消息 | 日式恋爱喜剧既视感 + 对照实验的核心逻辑一目了然 |
| 技术债务 | 借高利贷装修，每个月还利息比工资多 | 债务的压迫感直接可感 + "利息滚利息"完美映射技术债的雪球效应 |
| 递归 | 俄罗斯套娃拆到最里面那个发现是糖 | 视觉直觉 + "自己包含自己"的嵌套结构 + 结尾有惊喜 |
| 缓存 | 冰箱里常备可乐，省得每次跑超市 | 每个人都有"冰箱缓存"的体验 + 冷热数据=常喝/偶尔喝的饮料 |

## ❌ 失败比喻（概念对但效果差）

| 主题 | 比喻 | 为什么失败 |
|:---|:---|:---|
| A/B 测试 | 学校考试选择题，AB两个选项 | 太接近专业场景，没有反差。"考试"和"实验"都是严肃场景，缺乏降维感 |
| 递归 | 超市购物车里套了另一个购物车 | 太抽象，没有日常共鸣。谁会往购物车里套购物车？视觉上也不搞笑 |
| 负载均衡 | 食堂多开几个打饭窗口 | 比喻本身没错但太无聊，没有荒诞感。要的是"一群大妈抢着在一个窗口打饭被管理员分流到三个窗口" |
| 容器化 | 把东西装进收纳盒 | 太平淡，缺乏动作和戏剧性。应该是"合租屋里每个人把私人物品锁进自己的铁皮柜，谁也不碰谁的" |
| API | 餐厅菜单 | 经典比喻但完全没有恶搞感。要的是"你妈让你去隔壁借酱油，邻居大妈说'只借不还罚50块，每次最多借200ml'" |

## ⚠️ 渲染失败（比喻对但画面出问题）

| 问题 | 表现 | 修复方式 |
|:---|:---|:---|
| 人物画太大 | 人物占半屏高度，手绘批注和主题物件被挤到角落 | 提示词开头写"人物画小，约占画面 1/4 高度，周围留出大量空间放标注和物件" |
| 边框太多 | 每个漫画场景被画了矩形边框，变成了 PPT | 在提示词中写两遍"不要矩形边框"（一次在开头约束，一次在排版要求区） |
| 表情不夸张 | 人物一脸严肃地站在荒诞场景里，喜剧效果全毁 | 显式写"表情夸张滑稽，嘴巴张大，眼睛瞪圆"——不写模型就画中性脸 |
| 手写批注变成打印体 | 标注文字变成工整的宋体/黑体，破坏手绘氛围 | 写"手写批注风格，字迹潦草可爱"而非"标注" |
| 画面太挤 | 内容全部堆在一起，没有留白 | 写"段间距是正常行距的 2 倍，漫画场景之间至少留白一个人物高度的空间" |
| 配色跑偏 | 出现渐变色、阴影、3D 光影效果 | 写"严格只用：黑色线稿 + 青蓝标题 + 橙色气泡 + 红色箭头 + 米白底色，禁止渐变、阴影、3D 效果" |
