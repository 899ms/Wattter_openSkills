# 四格漫画 角色原型系统

## 默认角色原型

四格漫画使用三个功能原型角色，确保故事有提问者、活跃者和解释者的分工。用户可指定替换为特定 IP 角色，但三个功能角色必须保留。

### 原型 1：好奇者（Protagonist）

- **功能**：提出问题、犯常见错误、代表读者视角
- **性格**：天真好奇、容易困惑、认真学习、偶尔冒失但很真诚
- **外貌特征**：圆润造型，大眼睛闪烁好奇光芒，常带着问号表情
- **典型行为**：问"为什么？"、尝试后失败、恍然大悟、认真做笔记
- **在故事中的作用**：读者代入角色，通过TA的困惑和成长理解知识

### 原型 2：活泼者（Companion）

- **功能**：提供另一种思路、活跃气氛、推进情节
- **性格**：开朗活泼、点子多、偶尔调皮捣蛋、重视友谊
- **外貌特征**：活力感造型，表情丰富夸张，动作大开大合
- **典型行为**：突然冒出奇思妙想、用比喻解释、在紧张时搞笑、鼓励同伴
- **在故事中的作用**：打破僵局、提供不同角度、让学习过程有趣

### 原型 3：引导者（Guide）

- **功能**：解释要点、纠正误解、给予鼓励
- **性格**：温和沉稳、知识丰富、耐心鼓励、偶尔流露出可爱的一面
- **外貌特征**：略显成熟但不失可爱的造型，常带温和微笑
- **典型行为**：耐心解答、画出示意图、给予肯定、适时讲出金句
- **在故事中的作用**：知识传递者、情感支持者、故事的"定心锚"

## IP 替换规则

当用户指定某个 IP（如 Chiikawa、Line Friends、原创角色等）时，用该 IP 的角色替换三个原型角色。**替换原则：换皮不换骨**——保留三个角色的功能分工（提问者/活跃者/解释者），只替换外观和性格细节。

### 替换步骤

1. 识别用户指定的 IP 或角色
2. 将 IP 角色按功能映射到三个原型：
   - 最"普通/代入感强"的角色 → 好奇者
   - 最"活泼/出人意料"的角色 → 活泼者
   - 最"稳重/知识丰富"的角色 → 引导者
3. 保留原型的功能行为，但用 IP 角色的性格和语言风格来表达
4. 若 IP 角色多于3个，只选3个核心角色；若少于3个，可原创补充角色

### WTT 原创角色：小九

**定位：** 9号漫画的Q版宇宙版主角——从9号漫画的"黑框眼镜讲解员"变体而来，保留了辨识度极高的核心特征，但适配Q版可爱画风。

**视觉规范：**

| 部位 | 规范 | 禁止 |
|:---|:---|:---|
| 头型 | 正圆偏扁，略大（占身体 1/2-2/3） | 尖下巴、写实头型 |
| 眼睛 | 圆形大眼睛，黑框圆眼镜（保留9号漫画标志性特征），瞳孔有高光点 | 无眼镜、细长眼、写实眼 |
| 头发 | 黑色略乱的短发，头顶有一撮翘起来的呆毛 | 整齐发型、长发 |
| 身体 | 圆润梨形小身体，头身比 2:1-2.5:1 | 写实比例、细长身体 |
| 服装 | 白色圆领T恤，左胸口有个小"9"字logo | 复杂服装、西装 |
| 表情 | 默认开心微笑，困惑时歪头+问号气泡，恍然大悟时眼睛变星星 | 中性表情、无表情 |

**性格：** 好奇心爆棚的小百科迷，看到不懂的就忍不住问"为什么？"，偶尔冒失但很真诚。

**典型动作：**
- 歪头看人（困惑）
- 举手指天（恍然大悟）
- 双手捧书（认真学习）
- 拍脑袋（犯了低级错误）

**判断标准（pass/fail 测试）：**

| 测试 | 通过 | 失败 |
|:---|:---|:---|
| 去掉小九测试 | 移除小九后画面失去核心趣味和情感锚点 | 移除小九后画面信息完整——小九只是装饰 |
| 眼镜辨识度 | 去掉黑框眼镜就不像小九了 | 去掉眼镜仍是同一个人——眼镜特征不够鲜明 |
| 风格一致性 | 多页间小九看起来是同一只角色 | 第3页的小九和第1页不像同一人 |
| 呆毛测试 | 呆毛始终存在且方向自然 | 呆毛消失或变成别的发型 |

**WTT 小九配色方案：**
- 主色调：奶油色暖底（#FFF8E7）
- 角色色：黑白为主（黑发、黑框眼镜、白T恤）+ 胸口"9"字用橙色（#F97316）
- 强调色：柔蓝和薄荷绿（#87CEEB, #98FB98）
- 文字色：深棕色（#5D4037）

## 视觉风格变体

不同 IP 或主题可能需要不同的可爱风格。以下是几种常见变体：

### 日系可爱风格（默认）
- 圆润Q版造型，大眼睛小身体
- 温暖色调，柔和线条
- 适合：Chiikawa、Sanrio 系、学习类漫画

### 中式可爱风格
- 带有水墨/国风元素的Q版
- 红色/金色点缀
- 适合：传统文化、节日主题

### 扁平简约风格
- 几何化造型，色块分明
- 配色更现代（莫兰迪色系）
- 适合：科技、商业、数据可视化类主题

### 手绘涂鸦风格
- 粗糙线条，充满手绘质感
- 配色活泼跳跃
- 适合：创意、设计、个人表达类主题
