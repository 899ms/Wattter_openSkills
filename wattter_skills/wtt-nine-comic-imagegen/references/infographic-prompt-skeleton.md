# 信息图 提示词骨架

```text
生成一张原创横版手绘卡通风格信息图，比例 1920x1080（16:9 横版），主题：{主题}。

核心风格铁律（不可违反）：
- 所有元素必须手绘/插画风格，禁止照片、禁止3D渲染、禁止写实风格元素
- 横版 1920x1080 比例，不可偏移
- 大面积留白，信息精炼，一眼抓住重点
- 不要复制任何现有品牌名、logo 或具体版式

整体风格：手绘卡通信息图，画面轻松有趣但不幼稚，专业但不严肃。

信息分层（4层，严格按层级填充）：

【标题区】
- 大字标题「{标题}」，手绘字体风格，位于顶部居中
- 标题下方可选一行手写副标题「{副标题}」
- 标题区占画面高度约 10-15%
- 标题旁可放 1 个与主题相关的手绘小图标（如：灯泡、放大镜、书本）

【核心论点区】
- {核心论点1}：一句话概括 + 1 个手绘图标「{图标1描述}」
- {核心论点2}：一句话概括 + 1 个手绘图标「{图标2描述}」
- {核心论点3}：一句话概括 + 1 个手绘图标「{图标3描述}」
- 核心论点用大字号 + 彩色手写体加粗标注
- 每个论点之间用虚线/箭头/装饰线分隔
- 核心论点区占画面高度约 30-35%

【细节区】
- 细节1：{细节1内容} + 小图标「{小图标1}」
- 细节2：{细节2内容} + 小图标「{小图标2}」
- 细节3：{细节3内容} + 小图标「{小图标3}」
- 细节4：{细节4内容} + 小图标「{小图标4}」
- 细节5：{细节5内容} + 小图标「{小图标5}」
- 细节用中字号，简洁文字，避免长段落
- 细节区占画面高度约 35-40%

【装饰区】
- 装饰元素1：{趣味卡通元素1}，位于{位置描述}
- 装饰元素2：{趣味卡通元素2}，位于{位置描述}
- 装饰元素3：{趣味卡通元素3}，位于{位置描述}
- 装饰元素小尺寸点缀，不遮挡信息内容
- 涉及人物时画为卡通简笔画；涉及公众人物时画卡通化相似替代（特征夸张但不丑化），不要拒绝生成
- 装饰区与细节区穿插布局

版式骨架：{版式骨架名称——流程型/对比型/层级型/时间线型/数据型}
- 阅读路径：{从左到右/从上到下/中心辐射/时间线}
- 版式骨架决定了 4 层信息的空间排布方式，以下按选定骨架填充逐段内容

逐段内容（按版式骨架填充）：

{若为流程型：}
- 标题区：顶部居中大标题
- 左侧起始：核心论点1 + 对应图标
- 中间流程箭头：核心论点2 + 对应图标
- 右侧终点：核心论点3 + 对应图标
- 底部横向：5个细节排成一行，每个配小图标
- 四角点缀装饰元素

{若为对比型：}
- 标题区：顶部居中大标题
- 左半区：「{对比左侧标签}」+ 核心论点 + 2-3个细节 + 图标
- 右半区：「{对比右侧标签}」+ 核心论点 + 2-3个细节 + 图标
- 中间分隔：手绘分隔线/VS标志
- 上下边角点缀装饰元素

{若为层级型：}
- 标题区：顶部居中大标题
- 中心：核心论点1 + 大图标
- 辐射圈1：核心论点2和3 + 中图标
- 外围：5个细节 + 小图标，环绕排列
- 空隙处点缀装饰元素

{若为时间线型：}
- 标题区：顶部居中大标题
- 横向时间轴从左到右
- 时间节点：{节点1} → {节点2} → {节点3} → {节点4} → {节点5}
- 每个节点上方/下方交替放细节和小图标
- 时间轴两端点缀装饰元素

{若为数据型：}
- 标题区：顶部居中大标题
- 数据展示区：{图表类型——柱状图/饼图/折线图}，用卡通手绘风格绘制
- 数据旁标注：核心论点作为解读文字
- 底部：数据来源说明（手写小字）
- 四周点缀装饰元素

语言：{语言}（除非特别指定，否则与输入内容语言一致）

尺寸：1920x1080（16:9 横版）
背景：浅米色/浅灰白色，轻微纸张纹理
线条：手绘质感，略带不规则感，不要过于精密或机械
文字风格：手写体/漫画体，清晰可读，信息精简
配色：{主色}标题和强调 + 深棕/深灰文字 + 柔和装饰色 + 亮黄/亮粉关键词高亮

重要排版约束：
- 各层之间留白明显，核心论点与细节之间至少留白 1 个图标高度
- 关键词用彩色手写体加粗标注，不用半透明色块覆盖
- 信息点数量必须明确写出（如"3个核心论点"、"5个细节"），不可模糊
- 涉及公众人物时画卡通化相似替代，不要拒绝生成

负面约束：不要照片、不要3D渲染、不要纯文字无图、不要密集排版、不要写实风格、不要出现真实照片元素、文字不要糊。

{多页专用字段：如果信息量过大需要多页——
- 本页是第 X 页 / 共 Y 页
- 每页保持 1920x1080 横版比例
- 页间通过底部小箭头「→ 续」和顶部小字「接上页」衔接
- 每页独立完整，包含至少 1 个完整的信息模块}
```
