# 风格 C：四格漫画（完整参考）

Q版可爱多格学习漫画——用可爱的角色和简洁的视觉语言解释知识，让学习轻松有趣。

---

## 风格铁律（不可违反）

以下规则是四格漫画的视觉身份——违反任何一条，产出就不再是四格漫画。

1. **Q版比例严格 2:1-3:1**——头身比必须在此范围内。头太小或身体太长=失败。大眼睛、小身体、圆润造型，不可接近写实比例。
2. **3:4 竖版构图**——每页比例严格保持 3:4（如 1080x1440）。不是"大约3:4"，是严格 3:4。
3. **每页 2-4 格**——不可超过 4 格。格子太多=内容太挤=失败。
4. **温暖治愈基调**——故事主线积极向上，冲突温和，结局暖心。出现暗黑/恐怖/暴力=失败。
5. **三角色分工不可缺**——好奇者（提问/犯错）、活泼者（活跃/新角度）、引导者（解释/鼓励），三个功能缺一不可。用户可换皮（IP替换），不可换骨。
6. **配色温暖**——暖色基底 + 柔和强调色 + 深色文字确保可读性。冷色调为主=失败。

---

## 默认角色原型

| 角色 | 代号 | 性格 | 功能 |
|:---|:---|:---|:---|
| 好奇者 | Protagonist | 天真好奇、容易困惑、认真学习 | 提出问题、犯常见错误、代表读者视角 |
| 活泼者 | Companion | 开朗活泼、点子多、偶尔调皮 | 提供另一种思路、活跃气氛、推进情节 |
| 引导者 | Guide | 温和沉稳、知识丰富、耐心鼓励 | 解释要点、纠正误解、给予鼓励 |

**IP 替换规则：** 若用户指定了某个 IP（如 Chiikawa、Line Friends、原创角色），则用该 IP 的角色替换三个原型。替换时保留三个角色的功能分工（提问者/活跃者/解释者），只换皮不换骨。详细映射表见 [four-panel-character-archetypes.md](four-panel-character-archetypes.md)。

---

## 每页输出结构（4段式）

每页生成前，先规划以下 4 个维度，再写提示词：

```
// 学习目标 (LEARNING OBJECTIVE)
(说明这一页要传达的具体知识点和学习目标)

// 故事情节 (STORY CONTENT)
(描述角色对话、行动和情节发展，包含具体的知识讲解内容)

// 分格设计 (PANEL LAYOUT)
(详细描述每个分格的画面构成、角色位置、背景设置)

// 视觉重点 (VISUAL HIGHLIGHTS)
(说明需要特别突出的知识点、使用的视觉效果和强调方式)
```

## 工作流

### C1. 解析主题与角色分配

- 分析用户输入的学习内容，确定核心知识点
- 将知识点合理分解为 10-20 个学习点/情节节点
- 为三个角色分配合适的教学角色（好奇者提问/犯错 → 活泼者提供新角度 → 引导者解释/鼓励）
- 若用户指定 IP，按 [four-panel-character-archetypes.md](four-panel-character-archetypes.md) 中的映射规则替换角色

### C2. 生成视觉风格指令

在开始漫画创作之前，必须先输出一个全局性的视觉风格指令块（包裹在代码块中），包含：漫画风格描述、主要角色设定、画面构成规则、色彩方案、视觉元素。模板见 [four-panel-prompt-skeleton.md](four-panel-prompt-skeleton.md) 底部的「视觉风格指令块模板」。

**重要：视觉风格指令块只输出一次，作为独立代码块放在所有页面提示词之前。** 每页的提示词中不需要重复完整指令块，只需一行引用："遵循上方定义的视觉风格指令。"

### C3. 规划页面

- 根据内容复杂度合理规划总页数（建议 10-20 页）
- 每页对应 1-2 个学习点
- 第 1 页必须是封面（标题 + 角色群像 + 简短引言，不画格子）
- 最后一页必须是温馨结尾页（总结 + 角色成长 + 鼓励语，不画格子）
- **输出页面大纲表**：列出每页的页码、学习目标、一句话情节摘要，供用户确认

### C3.5 确认页面大纲（必须）

**在生成任何提示词之前，必须先让用户确认页面大纲表。** 这是一轮大纲反馈省掉多轮提示词返工的关键步骤。

展示格式：

| 页码 | 类型 | 学习目标 | 情节摘要 |
|:---|:---|:---|:---|
| 1 | 封面 | — | 角色群像 + 主题引言 |
| 2 | 内容 | {学习目标} | {一句话情节} |
| ... | ... | ... | ... |
| N | 结尾 | 总结 | 角色成长 + 鼓励语 |

询问用户："故事节奏和知识点分配是否合理？" 确认后才进入提示词生成。

### C4-C6. 分块生成提示词

对每一页：

1. 按 4 段式结构规划内容（学习目标 → 故事情节 → 分格设计 → 视觉重点）
2. 按 [four-panel-prompt-skeleton.md](four-panel-prompt-skeleton.md) 模板填充提示词
3. 将该页提示词输出给用户

**分块输出策略：** 每生成 3-5 页提示词后暂停，询问用户"继续生成第 X-Y 页？" 这样用户可以在过程中调整方向，而不是等 20 页全部输出后再发现问题。

### C7. 汇总输出

- 按页码顺序输出所有页的提示词
- 告知总页数

## 配色方案

- 底色：奶油色/淡黄色暖底
- 强调色：柔蓝、薄荷绿、浅珊瑚色
- 文字：深棕色
- 气泡/框线：浅色圆角边框，无边框阴影

---

## 关键要求

- 页面比例严格保持 3:4
- 对话自然流畅，避免说教式语言
- 通过角色互动自然传达知识
- 每页内容独立完整，同时与整体学习进度连贯
- 知识点讲解准确、清晰、循序渐进
- 充分利用漫画的视觉优势，用图像辅助理解抽象概念

---

## 绝对避免

- 生硬的知识灌输
- 过于复杂的单页内容
- 脱离角色性格的对话
- 超过 20 页的冗长内容
- 缺乏视觉吸引力的纯文字页面
- 暗黑/恐怖/暴力画面

---

## 提示词实战经验（风格 C）

1. **Q版比例必须写"头身比2:1-3:1, 大眼睛小身体"**——只写"Q版"产出比例不一致的角色；有的页头大身小，有的页接近正常比例。具体数字比模糊描述有效 10 倍。
2. **[N2 机制] 必须显式写"圆角格子边框"**——模型默认画直角矩形分格，和 Q 版可爱风格完全冲突。写成"圆角格子边框（浅色，无阴影）"一步到位。
3. **多页漫画必须在提示词中包含页码**——不写页码，模型会忘记叙事进度，产出情节跳跃或重复的内容。"第 3 页 / 共 12 页"让模型知道当前在故事的哪个位置。
4. **[N4 机制] 封面页和内容页的提示词要明显区分**——封面写"全页封面设计，不画格子"；内容页写"2-4 格分格漫画"。不区分的话模型会在封面上画格子或在内容页画全页插图。

## 风格 C 特有反馈

| 反馈 | 处理方式 |
|:---|:---|
| "不够可爱" | 强调Q版比例（头身比2:1-3:1）、圆润造型、大眼睛 |
| "角色出戏" | 检查角色行为是否符合原型性格，重新对齐功能分工 |
| "太说教" | 把知识讲解改成角色对话和互动场景，减少旁白 |
| "格子太密" | 减少每页格数（从4格减到2-3格），增加格间距 |
| "整体太冷" | 调整配色方案，增加暖色比例，使用推荐的暖色底色 |
