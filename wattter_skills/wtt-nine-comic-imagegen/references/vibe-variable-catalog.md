# 风格 E 变量池目录（vibe 摄影）

风格 E 的核心是「**主体固定 + 12 个变量池随机组合**」。本目录列出每个变量池的完整取值、组合禁忌和实战经验。

---

## 12 个变量池

### 1. 表情

> 描述主体的脸部情绪状态。vibe 摄影的关键是"刚发生的表情"，不是"标准 pose"。

- 抿嘴笑
- 抬眉（带点调侃）
- 歪头微笑
- 闭眼感受风
- 露半张脸（被头发或前景遮挡）
- 看镜头但眼神松散
- 看别处（45° 角外）
- 微笑不露齿
- 露齿笑（灿烂但不过分）
- 微张嘴（要说话前的瞬间）
- 害羞低头
- 挑眉（带疑问）
- 刚被打断的错愕
- 假装没听见
- 忍住笑的嘴角抖动

### 2. 服装

> 用**风格化标签**而非具体单品。模型懂风格标签，不一定懂单品细节。

- BM 风（短上衣 + 高腰裤）
- 辣妹吊带
- 白色 T 恤 + 牛仔裤
- 黑色连衣裙
- 针织开衫（米色或燕麦色）
- 复古学院风（百褶裙 + 西装外套）
- 纯欲风（蕾丝 / 缎面）
- 极简单色（黑 / 白 / 灰基础款）
- 运动休闲（卫衣 + 短裤）
- 毛衣 + 半裙
- 印花长裙（碎花或几何）
- 背心 + 工装裤
- 浴袍 / 居家服
- 旗袍改良款（带现代剪裁）
- 韩系女团私服
- 复古港风（红唇 + 缎面衬衫）

### 3. 场景

> 写"**地点 + 氛围**"，不要只写地点。模型对氛围词反应好（"清晨空荡的街道" > "街道"）。

- 荷塘 / 城市街道 / 咖啡馆 / 海边礁石 / 天台 / 便利店 / 公园长椅 / 老巷子 / 地铁站 / 卧室 / 浴缸边 / 商场扶梯 / 书架前 / 厨房 / 出租车后座 / 桥上 / 樱花树下 / 健身房镜前 / 民宿阳台 / 楼梯间 / 老式火车站 / 旧公交车内 / 河堤边 / 海边白色建筑 / 玻璃花房 / 楼顶停车场 / 旧码头 / 芦苇湖边 / 自动贩卖机前 / 老公寓楼梯间 / 雨后小巷 / 民宿落地窗边

### 4. 瞬间状态

> 描述"正在发生的事"。**优先选动作进行中的瞬间**，而不是动作完成后的标准姿势。

- 整理头发
- 回头看镜头
- 低头看手机
- 抬手撑伞
- 闭眼迎风
- 抬腿跨过门槛
- 蹲下系鞋带
- 靠墙翻书
- 抿咖啡杯边缘
- 撕包装袋
- 抬手遮光
- 伸懒腰
- 转身刚要开口
- 假装打电话
- 触摸墙面
- 弯腰触碰水面
- 沿木栈道缓慢行走
- 坐在船尾发呆
- 推开玻璃门
- 拉开窗帘
- 刚把头发放下来
- 用手背擦汗
- 从冰柜里拿饮料

### 5. 景别

> 框定人物在画面中的大小比例。**10 张里至少出现 3 种景别**。

- 大特写（脸/锁骨/手）
- 中近景（胸像）
- 中景（半身 / 腰部以上）
- 七分身（膝盖以上）
- 全身
- 远景人物（人在大场景中渺小，1/12 到 1/10 画面）
- 过肩镜头（视角在别人肩膀后）
- 第一人称视角（伸手向镜头）

### 6. 镜头焦段

> **必须明确写出数字焦段**（如 "85mm f/1.4"），不要只写"人像镜头"。每个焦段对应不同视觉语言。

| 焦段 | 视觉语言 | 适用场景 |
|:---|:---|:---|
| 24mm 超广角 | 强烈畸变、近大远小、空间压迫感 | 极低机位仰拍、抓拍强烈动感 |
| 28mm 街拍 | 经典街拍纪实感、环境代入强 | 街道、咖啡馆、半身 + 环境 |
| 35mm 经典 | 自然透视、最"像眼睛看到的" | 半身、七分身、人物 + 环境平衡 |
| 50mm 标准 | 真实透视、几乎无畸变 | 半身人像、日常感 |
| 85mm 人像 | 强压缩、背景虚化明显 | 半身 / 七分身特写 |
| 135mm 中长焦 | 强压缩、远距离感 | 抓拍远景、人物小比例 |
| 70-200mm 远摄 | 长焦压缩、背景虚化 | 远距离偷窥感 |

### 7. 机位

> 摄影师相对主体的位置。**10 张里至少 3 张非常规机位**（非平视）。

- 平视（眼高，最常用）
- 极低机位（贴地仰拍）
- 高机位俯拍（从楼上、桥上俯视）
- 肩上机位（从模特身后，露肩头前景）
- 膝盖高（从下往上 30°）
- 胸部高（从下往上 15°）
- 远距离机位（10 米以上）
- 倾斜 Dutch Angle（机位倾斜 5-10°）
- 透过门缝 / 窗缝 / 树枝缝隙拍
- 从楼梯扶手之间拍
- 摄影师边走边拍（运动模糊感）

### 8. 构图

> 人物在画面中的位置和比例关系。

- 居中构图
- 三分法（人物在左或右 1/3 线上）
- 黄金分割
- 对角线构图
- 中心对称
- 框架构图（拱门 / 窗户框住人物）
- 留白构图（人物在画面 1/4 处，大面积空白）
- 人物极小比例（环境大，人物占画面 1/12）

### 9. 前景

> **vibe 摄影的灵魂**——前景虚化、遮挡、反射是空间层次的来源。**必须显式写出前景**，模型默认不画前景。

- 透明玻璃带反光
- 雨滴 / 水珠
- 散焦的花瓣 / 树叶
- 透明伞
- 旧报纸
- 香烟烟雾
- 玻璃瓶
- 透明塑料袋
- 倒影水面
- 半开门
- 纱帘
- 路过的行人虚影
- 玻璃杯
- 车窗水滴
- 椅背
- 晾晒衣物
- 无前景（少数情况）

### 10. 光线

> **10 张里至少 4 种不同光线**，避免全是黄金时刻。

- 黄金时刻（黄昏侧光，暖金色）
- 阴天柔光（均匀漫射，无强烈阴影）
- 强烈日光斑驳（透过树叶缝隙）
- 室内台灯暖光（暖黄色单一光源）
- 霓虹灯混合光（蓝紫粉混合）
- 逆光剪影（背景亮、人物暗轮廓）
- 雨后湿润反光（地面反光强）
- 清晨冷蓝光（早晨偏冷调）
- 店铺橱窗光（暖黄透过玻璃）
- 单一硬光 / 伦勃朗光（侧光 + 阴影三角）
- 夜景路灯（暖黄孤光）
- CCD 直闪（直闪硬光 + 红眼）
- 室内暗而窗外高亮（强烈反差）

### 11. 色彩

> 用**摄影状态词 / 胶片型号**而非"暖色调"。"Kodak Portra 400" 比"暖色调"有效 10 倍。

- 胶片暖调（Kodak Portra 400 质感）
- 胶片冷调（Fujifilm 400H）
- 莫兰迪低饱和
- 90 年代复古偏黄（Olympus MJU 复古）
- 黑白胶片（Ilford HP5）
- 高对比黑白（街头纪实）
- 赛博朋克霓虹（青 + 紫 + 粉）
- 森系绿色调（浓郁绿）
- 奶油白调（柔和高光）
- 老录像带质感（VHS 噪点）
- VSCO film 滤镜感
- 理光 GR3 街头感（冷峻蓝灰）

### 12. 摄影状态

> 描述"这张照片是怎么拍的"——决定是抓拍感还是摆拍感。**默认偏抓拍**。

- 抓拍瞬间（轻微 motion blur）
- 假装被抓拍（对镜头半反应）
- 安静摆拍（pose 感，少数情况）
- 正在走路中
- 刚被打断的对话
- 凝固的瞬间（高快门，所有东西清晰）
- 慢门拖影
- 失焦边缘（主体边缘略糊）
- 边缘高光溢出
- 局部过曝
- 玻璃反射叠影
- 真实镜头眩光
- 自然颗粒感
- 轻微数码噪点

## 组合禁忌（避免组合出怪异结果）

| 禁忌组合 | 问题 | 替代方案 |
|:---|:---|:---|
| 极低机位 + 全身 + 24mm | 严重畸变（头大腿短）| 极低机位 + 大特写 或 + 中景 |
| 极低机位 + 全身 + 28mm | 仍有透视拉伸（边角畸变）| 极低机位 + 中近景 / 或全身 + 35mm+ 平视 |
| 全身 + 135mm + 平视 | 人物占画面太小，主体不清晰 | 全身 + 35mm + 平视 |
| 高机位俯拍 + 远景人物 | 看不清主体 | 高机位俯拍 + 七分身 |
| 赛博朋克霓虹 + 森系绿色调 | 风格冲突 | 一次只用一种色彩主题 |
| 慢门拖影 + 凝固的瞬间 | 自相矛盾 | 选其中一种 |
| 黑白胶片 + Kodak Portra 400 | 色彩风格冲突 | 黑白配 Ilford HP5 |

## 批次差异自检清单

生成 10 张前，逐项打勾：

- [ ] 景别：10 张里至少 3 种不同景别
- [ ] 焦段：至少 4 种焦段（不能用 10 张全是 35mm 或 85mm）
- [ ] 机位：至少 3 张非常规机位（非平视）
- [ ] 室内/室外：至少 3 张室内 + 3 张室外
- [ ] 光线：至少 4 种不同光线
- [ ] 服装：至少 6 种不同风格
- [ ] 相邻两张：共用变量 ≤ 6 个
- [ ] 12 池 × 10 张的"多样性分数"：每列 unique 值数 ≥ 4

如果某项不达标，回到对应池重抽 1-2 张，确保整批视觉差异明显。

---

## 实战经验

1. **批次差异先于单张完美**——10 张里有 2 张"差一点"可以接受，10 张同质化是失败的批。
2. **机位是 vibe 的最大变量**——同一人物、同一服装、同一场景，只换机位（极低 vs 高俯 vs 平视）就能产生完全不同的情绪。
3. **前景词比构图词更具体**——"散焦的树叶前景" 比"虚化前景" 有效；模型需要看到具体物件。
4. **光线带情绪**——黄金时刻 = 浪漫，阴天柔光 = 文艺，霓虹 = 都市，CCD 直闪 = 复古。
5. **服装的"风格标签 > 单品描述"**——"BM 风" 模型懂，"白色吊带背心 + 高腰牛仔短裤" 模型可能画错细节。
6. **场景的"地点 + 时代感"**——"90 年代老巷子" > "老巷子"；"清晨 5 点便利店" > "便利店"。
7. **摄影状态词是 vibe 的灵魂**——必须写"Kodak Portra 400" / "CCD 直闪" / "理光 GR3" 这类具体词。
8. **不要让所有人物都看镜头**——10 张里至少 5 张主体不直视镜头（看别处 / 闭眼 / 低头 / 抬伞）。
9. **不要画成影楼风**——避免棚拍白底 + 完美对称 + 标准 pose + 全脸光。
10. **允许局部遮挡**——前景虚化的树叶遮住脸部边缘、肩部、手臂都允许，不要为了完整展示人物而移除遮挡。
