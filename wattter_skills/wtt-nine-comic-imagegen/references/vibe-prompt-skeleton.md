## 批次生成前自检清单

每次生成 10 张前，逐项打勾：

- [ ] **景别多样性**：10 张里至少 3 种不同景别（特写 / 半身 / 全身等）
- [ ] **焦段多样性**：至少 4 种焦段（如 24/28/35/50/85mm 至少出现 4 种）
- [ ] **机位多样性**：至少 3 张非常规机位（极低 / 高俯 / 肩上 / 倾斜）
- [ ] **室内/室外**：至少 3 张室内 + 3 张室外
- [ ] **光线多样性**：至少 4 种不同光线
- [ ] **服装多样性**：至少 6 种不同风格
- [ ] **相邻两张**：共用变量 ≤ 6 个
- [ ] **肖像权检查**：每张都有"不画成任何具体公众人物的相似脸"约束
- [ ] **N1 机制**：硬约束"真实生活摄影感"在开头和结尾各写一次
- [ ] **N 比例锚定**：每张都明确写具体像素数（不只是"竖版"）

## 用户指定字段锁定规则

### 完全锁定模式

用户说："**荷塘 + BM 风 + 28mm + 极低机位**"
→ 这 4 个字段锁定为所有 10 张的统一基线
→ 剩余 8 个变量在 10 张内差异化

### 字段锁定模式

用户说："**全用黄金时刻 + 全身 + 35mm**"
→ 这 3 个字段锁定
→ 剩余 9 个变量自由组合

### 计数锁定模式

用户说："**10 张里至少 3 张室内**"
→ 室内场景至少 3 张，其他 7 张自由

### 风格锁定模式

用户说："**偏复古胶片感**"
→ 色彩池锁定为"胶片"类（Kodak Portra / Fujifilm 400H / Olympus MJU / Ilford HP5）

---

## 用户指定内容的优先级

**用户明确指定的字段优先级最高**，绝不可替换或修改。

例如：
- 用户指定"BM 风" → 不允许换成"白色 T 恤"
- 用户指定"极低机位" → 不允许换成"平视"
- 用户指定"荷塘" → 不允许换成"城市街道"

其他未指定的字段保持随机组合。

```text
【批次 #1 / 共 10 张】
主体：一位极具镜头感的韩国 INS 网红，皮肤白皙，身材傲人，五官精致但不网红脸，自然有生活感。
【本次变量组合】
- 表情：抿嘴笑 / 服装：BM 风 / 场景：荷塘边 / 瞬间状态：回头看镜头
- 景别：中近景 / 焦段：24mm 超广角 / 机位：极低机位（贴水面 10cm）
- 构图：右侧 1/3 留白构图 / 前景：水面的荷叶边缘虚化
- 光线：清晨冷蓝光 / 色彩：Kodak Portra 400 暖调 / 摄影状态：轻微 motion blur

【自然融合后的完整提示词】
（80-150 字中文摄影提示词，融合上述 12 个变量）

【批次 #2 / 共 10 张】
（同样的主体锚点 + 不同的 12 个变量组合）
...
```

**为什么先列变量再融合**：
- 让用户能快速看 10 组的差异（一眼看清单）
- 实际喂给模型的只有"自然融合后的完整提示词"段
- 变量清单是给用户读的"对照表"，让他能立刻指出"第 5 张的服装换成针织开衫"

## 自然融合 8 步公式

将 12 个变量融合成 80-150 字的一段中文摄影提示词，按以下顺序：

1. **机位 + 焦段**开头（建立镜头感）
2. **场景**（点明地点）
3. **主体 + 服装**（引出人物）
4. **动作/瞬间状态**（人是活的）
5. **表情/视线**（情绪锚点）
6. **光线**（影调）
7. **前景/景别/构图**（层次）
8. **摄影状态 + 色彩**（最终风格）

### 反例（结构化罗列，模型表现差）

```
场景：荷塘。服装：BM 风。焦段：28mm。机位：极低。
光线：黄昏。表情：看镜头。构图：三分法。
```

### 正例（自然融合，模型表现好）

```
极低机位贴在水面上 10cm，28mm 广角拍荷塘边的小路，一位穿 BM 风短上衣
的韩国 INS 网红正回头看镜头，逆光剪影发丝微亮，手里提着草帽，
表情带着刚回头时的好奇，黄昏金色侧光打在她侧脸，浅景深前景虚化
两三片荷叶，整体像刚被抓拍的胶片瞬间，Kodak Portra 400 暖色调。
```

## 适用场景 vs 不适用场景

### 适用

- 个人小红书 / INS 头像
- 公众号 / 博客配图（生活类）
- 摄影作品集 / 个人品牌
- 模特卡片 / 约拍摄影 prompt
- 写真类商业用途（自审肖像权）

### 不适用

- 证件照 / 工作照（用棚拍白底）
- 严肃商业广告（用品牌产品图）
- 全家福 / 多人合影（vibe 风格单人为主）
- 需要清晰文字展示的图（vibe 风格画面文字少）
